# 英文插图中文重绘规范

## 1. 什么时候重绘

满足任一条件就重绘，不要在原图上贴中文：

- 图内文字是英文（标题、环节名、注释任意一处）
- 原图分辨率低（宽度 < 1000px）
- 原图是扫描件、有水印、背景发灰

只在原图上贴中文的唯一情形：图是照片或复杂插画，重绘会丢失信息。此时用与背景同色的圆角矩形盖住原文，再叠中文，并保持字号不小于原文字号的 90%。

## 2. 译名规范

- 标题译成名词短语，不加书名号、不加句号
- 环节名译成动词短语或状态短语，彼此字数接近，便于对称排版
- 术语与导图正文保持一致；同一概念全书只用一个译名
- 公司、产品、人名、通用缩写保留原文：Facebook、VISA、AT&T、IBM、GPT
- 不硬译双关与口号；必要时改写成直白说法，并在导图 alt 里保留英文原意

译完先列一张对照表给自己核对，再动手画。

## 3. 画布与版式

统一画布宽度 1280，高度按内容 780–1000。四边留白：上 60、下 60、左右 120（有侧边标签时该侧加到 200）。

### 3.1 循环图（四节点，最常见）

菱形布局，中心 (640, H/2)，节点半径 92：

| 节点 | 坐标 |
|---|---|
| 上 | (640, cy - 222) |
| 右 | (960, cy) |
| 下 | (640, cy + 222) |
| 左 | (320, cy) |

弧线连接相邻节点，控制点取两点中点再沿"背离中心"的法线外推 28–30px，形成外鼓弧。起止点各从圆心沿连线退 92px，箭头才不会被圆压住。

### 3.2 线性流程（4–6 步）

节点等距横排，间距 = 画布宽 / (n + 0.6)。每步用圆角矩形（宽 200、高 110、圆角 14），箭头为水平直线，标签放在矩形内部而不是下方，避免拥挤。

### 3.3 金字塔 / 层级

自下而上 4–6 层，顶层窄、底层宽，宽度按 0.42、0.6、0.78、0.96 的梯形比例。右侧配一条带箭头的竖轴，标"基础"与"最终目的"。

### 3.4 矩阵 / 对照表

2×2 或 3 列对照。表头用浅色底（#EEF3F8），行分隔用 1px 虚线 #C9D6E2，不要用实线网格，视觉更轻。

## 4. 样式 token

| 用途 | 值 |
|---|---|
| 正文与描边 | #26333F |
| 标题 | #1B2733，31px，700 |
| 副标题 | #7A8894，17px |
| 节点头标签 | #26333F，23px |
| 连接箭头 | #7C8FA0，2.6px |
| 节点填充 | #FBFCFD |
| 强调色（少量） | #2F6B9A |
| 画布底色 | #FFFFFF |
| 字体 | Microsoft YaHei, PingFang SC, Noto Sans SC, sans-serif |

节点圆圈描边 2.4px、填充近白，不加阴影与渐变——投影在打印和深色主题下都会脏。

## 5. SVG 骨架

```svg
<svg xmlns="http://www.w3.org/2000/svg" width="1280" height="900" viewBox="0 0 1280 900"
     font-family="Microsoft YaHei, PingFang SC, Noto Sans SC, sans-serif">
  <defs>
    <marker id="ah" viewBox="0 0 10 10" refX="8" refY="5" markerWidth="6" markerHeight="6" orient="auto">
      <path d="M0,0 L10,5 L0,10 Z" fill="#7C8FA0"/>
    </marker>
  </defs>
  <rect width="1280" height="900" fill="#FFFFFF"/>
  <!-- 标题 -->
  <text x="640" y="60" text-anchor="middle" font-size="31" font-weight="700" fill="#1B2733">中文标题</text>
  <!-- 节点 -->
  <circle cx="640" cy="256" r="92" fill="#FBFCFD" stroke="#26333F" stroke-width="2.4"/>
  <!-- 弧线 -->
  <path d="M715.6,308.4 Q817.1,342.4 884.4,425.6" fill="none" stroke="#7C8FA0"
        stroke-width="2.6" marker-end="url(#ah)"/>
  <!-- 标签 -->
  <text x="640" y="148" text-anchor="middle" font-size="23" fill="#26333F">环节一</text>
</svg>
```

注意：

- `marker` 必须写 `orient="auto"`，否则箭头方向固定
- 文字用 `text-anchor="middle"` 居中，左右侧标签用 `start` / `end` 对齐
- 中文行高按 1.45 倍字号排，两行标签行距 34px
- 不要在 SVG 里用外链字体，渲染环境可能没有

## 6. 图标画法

原图若用人物线稿，重绘时可换成等价几何符号，语义更清楚，也不容易画歪：

| 含义 | 符号 |
|---|---|
| 增加 / 更多 | 并排双上箭头 |
| 减少 | 三条递减横条（长度 56 / 38 / 18） |
| 退化 / 下降 | 阶梯折线 + 向下箭头 |
| 循环 / 依赖 | 300° 圆弧 + 箭头 |
| 汇聚 | 两条弧线汇入一点 |

线宽 4px，`stroke-linecap="round"`，颜色同正文 #26333F。

## 7. 渲染与目检

```bash
python scripts/svg2png.py "图.svg" --scale 2
```

渲染完必须用 `ViewImage` 看一眼，逐项确认：标题与标签不重叠、标签不出画布、箭头首尾相接、图标居中。发现挤了就调坐标重渲，不要凭想象交付。

本机 Chrome 常被沙箱拒绝执行，脚本会自动退到 Edge；单独调用时用：

```bash
"/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" --headless=new \
  --force-device-scale-factor=2 --window-size=1280,900 \
  --screenshot="out.png" "file:///C:/path/to.svg"
```

## 8. 命名与归档

- 新图：`图片/<序号>-<中文主题>-中文版.png`，SVG 同名保留，便于改字
- 原英文图：移到 `图片/全部插图/`，不改名、不删除
- 导图引用写 `![中文重绘：<图意>（环节A → 环节B → 环节C）](图片/xxx.png)`，alt 里把因果顺序说全，导图工具不显示图片时仍可读

## 9. 插入位置

插在它所属小节的正文节点之后、下一节标题之前。同一张图在详细版与精简版都可以放，但精简版最多 1–4 张，只放能撑起整章骨架的那种。
